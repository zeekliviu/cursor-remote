# Google Play content rating (IARC questionnaire)

Complete **Play Console → App content → Content rating**. Start a new questionnaire for Android. Use these answers for Cursor Remote (productivity / utility companion app).

## Category / app type

| Prompt | Answer |
|--------|--------|
| App category | **Utility, Productivity, Communication, or Other** (pick **Productivity** / Utility if listed) |
| Does the app contain user-generated content that is shared publicly? | **No** (chats stay on the user’s own host; no public feed) |
| Is the app a web browser / search engine / email client? | **No** |
| Does the app primarily provide news / magazines? | **No** |

## Violence

## Misc / age

| Prompt | Answer |
|--------|--------|
| Shares user location | **No** |
| Allows unrestricted web access / browser | **No** |

## Expected outcome

Typically **Everyone** / **PEGI 3** / equivalent low age rating for a productivity utility with no objectionable media.

Save the certificate email and keep the questionnaire up to date if features change.
